# Sankalp Portfolio

A responsive personal portfolio built with React, TypeScript, Vite, and Tailwind CSS. It uses a dark, grid-backed card layout inspired by [hiimvikash.dev](https://hiimvikash.dev/) and keeps all portfolio copy and project details in `src/content.ts`.

## Run locally

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```

The static production site is generated in `dist/` and can be hosted by Vercel or another static host.

## Content

Verified project summaries and technologies are based on the local Bit Tracker, MERA BHARAT, and Expenses project READMEs. Add professional experience, education, milestones, and proof-of-concept items to `src/content.ts` when those details are ready to publish.
